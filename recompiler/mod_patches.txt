# recompiler/mod_patches.txt - parches de los mods de lógica (D58).  Formato, una línea por parche:
#   DIRECCION | texto_a_sustituir | texto_nuevo
# gen_c.py busca `texto_a_sustituir` EXACTAMENTE UNA VEZ en el C que emite para la instrucción de esa dirección y lo cambia por
# `texto_nuevo`.  Todos los parches dependen de c->mod_wide (píxeles extra de pantalla ancha por lado, 0 = juego original) y valen
# lo mismo que el original cuando es 0: con el mod apagado el código generado se comporta igual que sin este archivo, y se
# comprueba con los CRC de estado de tools/sequences/ (playgen.py --verify).  Ni los ciclos ni el reloj de MAME cambian.
#
