SF2Recomp Street Fighter II: The World Warrior (CPS1) recompilado a C y WebAssembly

Un solo código fuente en macOS, Linux, Windows y el navegador. Necesitas tu propia copia de las ROMs.

Elige tu sf2.zip (el del set sf2 de MAME, World 910522) o arrástralo aquí.

El archivo se lee en tu navegador y no se envía a ningún servidor. Esta página no incluye ROMs. Este build se generó a partir de tus ROMs (el programa del 68000 va traducido dentro del .wasm): es para tu uso personal, no lo publiques.
